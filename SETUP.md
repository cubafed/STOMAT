# Радикс — подключение бэкенда (Supabase)

Приложение работает и без бэкенда (данные в браузере). Чтобы данные
сохранялись в облаке и были доступны на всех устройствах и у всей команды
клиники — подключите Supabase.

## 1. Проект уже привязан
В `project/assets/config.js` прописаны URL и publishable-ключ вашего проекта
`ouqzjceshailooyhsssh`. Publishable-ключ публичен по дизайну — доступ к данным
ограничен политиками RLS, поэтому хранить его в репозитории безопасно.

## 2. Создать таблицы
1. Откройте Supabase → ваш проект → **SQL Editor** → New query.
2. Скопируйте всё содержимое `project/assets/schema.sql` и нажмите **Run**.
   Создадутся таблицы `clinics`, `profiles`, `kv`, `public_bookings`, политики
   RLS и триггер, который при регистрации заводит клинику и профиль.

## 3. Включить вход по email
Supabase → **Authentication → Providers → Email** → включить.
Для быстрых тестов можно выключить «Confirm email» (Authentication → Settings),
чтобы входить сразу после регистрации без письма.

## 4. Готово
- Регистрация на странице «Вход и регистрация» создаёт клинику и аккаунт врача.
- После входа все данные (пациенты, планы, оплаты, воронка, настройки)
  зеркалятся в таблицу `kv` вашей клиники и подтягиваются на любом устройстве.
- В кабинете справа вверху — индикатор: «Войти для синхронизации» или
  «Синхронизация · выйти».

## Что НЕ уходит в облако
- Загруженные снимки (`rdx_img_*`) — тяжёлые, остаются локально в браузере.
- Ключ OpenAI (`radix_ai_*`) — только в браузере врача.

## Локальный режим
Очистите `supabaseUrl` в `config.js` — приложение вернётся к чисто локальному
хранению (демо/офлайн), без обращений к сети.
